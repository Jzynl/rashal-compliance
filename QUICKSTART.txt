RASHAL ENERGIES - COMPLIANCE MANAGEMENT SYSTEM
==============================================

WINDOWS QUICK START
-------------------
  pip install -r requirements.txt
  copy .env.example .env
  python manage.py migrate
  python manage.py bootstrap_roles
  python manage.py seed_demo
  python manage.py runserver

Then open:  http://127.0.0.1:8000/django-admin/

WHAT WORKS RIGHT NOW
--------------------
  Setup > Compliance types    add a type -> auto-created on all 14 stations
  Setup > Stations            add a station -> all 14 compliances auto-created
  Setup > Users               assign role + stations (many-to-many)
  Compliance periods          enter dates -> old period auto-superseded
  python manage.py scan_compliance --dry-run    see what alerts would fire

WHAT IS NOT BUILT YET
---------------------
  - Templates (the front-end HTML). Views and URLs are wired; the admin
    is the working UI meanwhile.
  - Renewal wizard screens.
  - Weekly digest command.
  - Per-recipient daily SMS cap. DO NOT set SMS_BACKEND=beem until this
    exists - the scan currently sends ~200 SMS/day across 36 expired
    obligations.

USE POSTGRESQL
--------------
Edit .env:
  DB_ENGINE=postgres
  DB_NAME=rashal_compliance
  DB_USER=postgres
  DB_PASSWORD=yourpassword
  DB_HOST=127.0.0.1
  DB_PORT=5432

Then: python manage.py migrate

DAILY ALERT SCAN (cron / Task Scheduler, 06:00 EAT)
---------------------------------------------------
  cd /srv/rashal && python manage.py scan_compliance
